## ✨ 功能

通过 Google Lens 对图片进行反向检索，解析 **Exact matches（完全匹配）** 结果，
返回收录该图片的页面地址与标题：

```
【图片描述】
这张图片是轻小说及衍生动画《青春猪头少年系列》中女主角樱岛麻衣的官方同人
全彩画集《Bunny A Girl!》的封面。该画册由该系列的官方小说插画师沟口凯吉
（溝口ケージ）所属的社团「NtyPe」制作，并于 2018 年底在 Comic Market 95
（C95）展会上现场限量发售。

找到以下结果
1. 链接: https://shop.lashinbang.com/products/detail/2273450
标题: BUNNY A GIRL! 【青春ブタ野郎 シリーズ】[溝口ケージ][NtyPe]
来源: らしんばんオンライン
```

### 特性

- **两种结果模式**：AI 图片描述（说明这是什么）与完全匹配（收录该图的网页），
  默认都开，可分别关闭
- 浏览器内核缺失时自动安装，无需手动准备运行环境
- 支持 PNG / JPEG / WebP / BMP；动图（GIF / 动态 WebP / APNG）自动提取首帧
- 结果为可直接打开的来源页面地址，而非 Google 跳板链接
- 默认关闭安全搜索过滤，不受出口 IP 所在地区的默认设置影响
- 可选补全被 Google 截断的标题
- 可选附带图片内文字（调用 Lens 的 OCR 接口）
- 触发人机验证时自动重试
- 浏览器空闲后自动关闭以释放内存
- 提供 LLM 函数工具，可由大模型在对话中直接调用
- **无需 Google 账号**，全程使用匿名会话

## 🚀 快速开始

1. 打开 AstrBot WebUI → 插件市场搜索 `astrbot_plugin_image_search` 并安装
2. 在插件配置中填写**浏览器 → 代理地址**（中国大陆部署必须配置）
3. 等待浏览器内核在后台自动下载完成（约 170 MB，耗时 2~5 分钟）

第 3 步无需干预。下载期间发送指令会收到安装进度提示，装好后即可正常使用；
管理员可发送 `/搜图状态` 查看进度。

## 💬 使用

| 指令 | 别名 | 权限 | 说明 |
| --- | --- | --- | --- |
| `/搜图` | `soutu` / `sauce` / `以图搜图` | 所有人 | 图片反向检索 |
| `/搜图状态` | `soutu_status` | 管理员 | 查看浏览器状态与安装进度 |

`/搜图` 支持三种输入方式：

| 输入方式 | 说明 |
| --- | --- |
| 指令带图 | `/搜图` 与图片位于同一条消息 |
| 引用图片 | 引用包含图片的消息并回复 `/搜图` |
| 补发图片 | 先发送 `/搜图`，随后补发图片（默认等待 60 秒） |

单次检索约 20~30 秒。插件同时注册了 LLM 函数工具 `reverse_image_search`，
可由大模型在对话中直接调用。

## 🌐 配置代理

Google Lens 需要访问 `lens.google.com` 与 `www.google.com`，中国大陆部署必须配置
代理。填写位置：插件配置 → **浏览器 → 代理地址**，例如 `http://127.0.0.1:7897`。

Docker 部署时请注意：**不能填代理容器的名称**，两个容器通常不在同一 docker
network 内。建议填写宿主机的局域网 IP，例如 `http://192.168.1.100:7890`。

> 机房 IP 触发人机验证的概率显著高于住宅 IP。插件内置重试机制，可覆盖大部分
> 偶发失败。

## ⚙️ 配置

全部配置项在 WebUI 的插件配置页中修改，均有默认值。下表仅列出需要说明的项，
其余保持默认即可。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| **代理地址** | 空 | **中国大陆部署必填** |
| 返回完全匹配结果 | 开 | 收录该图片的网页列表 |
| 返回 AI 图片描述 | 开 | 用自然语言说明这是什么。图片没被任何网页收录时往往仍能给出答案，代价是多花约 10 秒 |
| 开启安全搜索过滤 | 关 | 开启后命中过滤的图片会返回 0 条结果，而非部分过滤 |
| 最多返回条数 | 10 | 只影响完全匹配的条数；Google 单页通常返回 20 条以上 |
| 结果页语言 | en | 影响标题与站点名的语言，不影响匹配结果 |
| 补全被截断的标题 | 开 | 详见〈已知限制〉 |
| 附带图中文字 | 关 | 额外返回图片内识别出的文字 |
| 使用合并转发消息 | 开 | 结果打包成一条合并转发，不占聊天记录；关闭则逐条发普通消息 |
| 合并图片描述与完全匹配 | 关 | 两类结果是否放进同一条消息，与上一项互不影响 |
| 链接单独成一条消息 | 关 | 方便长按复制：`标题（来源）` 一条、纯链接一条，结果间插横线分隔；此模式不显示序号与字段名。仅在开启合并转发时可配 |
| 空闲多久关闭浏览器 | 30 分钟 | 设为 0 表示常驻，可省去启动开销，但会占用数百 MB 内存 |
| 同一用户冷却 | 15 秒 | 避免请求堆积 |
| 人机验证重试次数 | 2 | |

其余配置项包括自动安装策略、浏览器路径与超时、消息输出格式（序号、站点名、
图片尺寸的显隐及提示语文案）、等待补图时长。

搜图结果由插件直接投递，因此 AstrBot 全局设置中的「转发消息的字数阈值」、
「回复时引用发送人消息」与文本转图片均不作用于它 —— 结果是否折叠只取决于上面
三个配置项，不会随字数变化而时有时无。

宿主机已安装 Chrome / Chromium / Edge 时，插件会优先使用系统浏览器，不再下载。
需要自行管理浏览器的场景见 [ARCHITECTURE.md](docs/ARCHITECTURE.md#61-手动管理浏览器)。

## 🩺 排错

管理员可先发送 `/搜图状态` 查看浏览器与安装状态。

| 现象 | 处理方式 |
| --- | --- |
| 提示正在安装浏览器 | 等待几分钟后重试，首次安装需下载约 170 MB |
| 提示浏览器启动失败 | 交由管理员处理，通常是代理未配置或运行环境缺少依赖 |
| 提示搜索超时 | 稍后重试。刚安装或更新过插件时，请让管理员重启一次 AstrBot |
| 稳定返回「没有找到完全匹配的结果」 | 先用其他图片确认；若所有图片都无结果，检查代理是否可用 |
| 提示触发人机验证 | 稍后重试；频繁出现则更换代理节点 |
| 单次耗时明显超过 30 秒 | 检查代理速度与稳定性 |
| 提示搜图冷却中 | 等待冷却结束，或由管理员调整冷却时长 |

图片本身没有被任何网站收录时，返回无结果属于正常情况 —— 完全匹配要求网络上存在
同一张图片。建议先用一张来源明确的图片验证插件是否正常。

管理员排查手段与故障对照见 [ARCHITECTURE.md 第六节](docs/ARCHITECTURE.md#六部署与运维)。

## 📌 已知限制

- **标题可能不完整。** Google 返回的标题过长时会被截断为 `xxx ...`。开启「补全被
  截断的标题」后插件会尝试抓取来源页标题补全，但部分网站有访问限制，补全失败时
  保留截断后的标题。
- **检索串行执行。** 单次约 20~30 秒，多人同时使用会排队，用户冷却机制用于避免
  请求堆积。
- **必须能够访问 Google。** 不存在可绕过该前提的替代方案。
- **完全匹配只认同一张图。** 相似图片、二次创作、裁剪程度较大的版本不在结果内；
  这类图片可以靠 AI 描述得到线索。
- **AI 描述的语言不固定。** 由 Google 按出口 IP 判定，同一张图换代理节点可能
  从中文变成英文。另外它对少数图片会拒答，此时只返回完全匹配。
- **AI 描述保留 Google 的原始回答。** 其中可能包含「如果你想了解更多，我可以为你
  提供……」这类邀请继续对话的内容。这部分与描述正文在页面结构上无法区分，过滤存在
  误删正文的风险，因此保留。
- **Google 改版后可能需要更新插件。** 结果解析依赖页面结构，改版后可能需要等待
  插件适配。
